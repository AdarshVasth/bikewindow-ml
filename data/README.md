# Original sample data

`daily_demand.csv` contains 730 fictional daily records generated by `sample_data(seed=2026)`. The dates, weather and rental counts are synthetic. No city, company, station, rider or real weather source is represented. Generated data, code and outputs may be redistributed under this repository's MIT license.

Columns: `date` (ISO daily date), `temperature_c` (°C), `rain_mm` (daily rainfall mm), `holiday` (0/1 fictional event flag), `rentals` (nonnegative integer count).

The simulator combines annual weather seasonality, independent randomized rain and holiday flags, weekend effects, a temperature curve, log-normal unobserved daily noise and Poisson count noise. This process is intentionally learnable and does not simulate all real-world constraints.

`metrics.json` and `holdout_predictions.csv` are measured outputs from `python evaluate.py`; they are not hand-authored performance claims. Regeneration overwrites only these three known project data files.
